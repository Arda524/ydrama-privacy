# Ydrama Privacy Policy

This repository contains the public privacy policy page used for the Ydrama Android app.

## Purpose

This page is published online so it can be used as the Privacy Policy link in Google Play Console for the Ydrama app.

## Files

- `privacy_policy.html` — the public privacy policy page
- `privacy_policy.md` — markdown version of the same policy

## Live URL

Use the published Netlify URL in Google Play Console, for example:

- https://ydrama.netlify.app/privacy_policy.html

## Notes

This page is intentionally public and simple to host on Netlify, GitHub Pages, or any static web host.
